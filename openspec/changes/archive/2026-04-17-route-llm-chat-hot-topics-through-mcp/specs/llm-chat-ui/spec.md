## ADDED Requirements

### Requirement: 热点卡片保留既有样式
热点问答消息中的新闻卡片 SHALL 保持当前已上线的视觉样式、层级和点击交互，仅允许替换数据来源与新增标题下描述插槽，不得借本次变更重做卡片布局。

#### Scenario: 现有卡片样式保持不变
- **WHEN** 用户查看热点问答中的新闻卡片
- **THEN** 系统 MUST 保持现有卡片容器、分组结构、标题样式、meta 信息和点击打开原文的交互行为不变

#### Scenario: 来源标签保持在标题后
- **WHEN** 热点卡片展示标题、摘要和 meta 信息
- **THEN** 系统 MUST 将来源标签保持在新闻标题后方，不得把来源渲染进摘要占位区域或时间 meta 区域

### Requirement: 基于 MCP JSON 的渐进渲染
热点卡片 SHALL 直接消费聊天编排层提供的 MCP JSON 数据渲染，并支持单条新闻描述的渐进更新。

#### Scenario: 结构化热点直接渲染
- **WHEN** 前端收到热点卡片 payload
- **THEN** 系统 MUST 使用其中的结构化字段直接渲染新闻标题、来源、时间和链接，不依赖从正文 markdown 中反向提取卡片信息

#### Scenario: 描述加载中显示占位动画
- **WHEN** 某条新闻的一句话描述尚未返回
- **THEN** 系统 MUST 在该新闻标题下显示加载动画或等价占位态，直到对应描述结果返回或任务结束

#### Scenario: 描述返回后原位替换
- **WHEN** 前端收到某条新闻的描述补丁事件
- **THEN** 系统 MUST 只更新对应新闻项的描述区域，不得重排整张卡片或覆盖其它已完成新闻项的状态

#### Scenario: 描述失败时保留描述区高度
- **WHEN** 某条新闻描述为空、失败或被取消
- **THEN** 系统 MUST 保留标题下描述区的占位高度，并显示等价的占位文案，避免来源或时间信息上移造成视觉错位

### Requirement: K-Ai 页面访问与滚动体验
K-Ai 页面 SHALL 在不打断当前阅读上下文的前提下处理登录限制与流式滚动行为。

#### Scenario: 未登录访问 K-Ai 停留当前页并提示
- **WHEN** 未登录用户尝试访问 `/assistant`
- **THEN** 系统 MUST 取消本次导航、保持当前页面不跳转，并显示 warning toast “请登录”

#### Scenario: 默认自动跟随最新内容
- **WHEN** 用户尚未手动滚动消息列表且流式回答持续生成
- **THEN** 系统 MUST 默认保持消息视口跟随最新一行内容

#### Scenario: 用户手动上滑后停止抢夺滚动
- **WHEN** 用户主动向上滚动消息列表查看历史内容
- **THEN** 系统 MUST 暂停自动贴底，不得因为后续流式 token、thinking 或状态更新再次强制滚动到底部

#### Scenario: 显示一键到底按钮
- **WHEN** 消息列表已脱离底部且存在更新中的内容或未读的新内容
- **THEN** 系统 MUST 显示一个悬浮的圆形“一键到底”按钮，供用户快速返回最新位置

### Requirement: 消息时间展示
聊天消息 SHALL 在气泡下方显示层级化的时间文案，并以低干扰样式呈现。

#### Scenario: 时间文案按日期层级展示
- **WHEN** 系统渲染消息时间
- **THEN** 当日消息 MUST 显示 `xx:xx`，同年非当日消息 MUST 显示 `x月x日 xx:xx`，跨年消息 MUST 显示 `xxxx年x月x日`

#### Scenario: 时间默认淡显 hover 加深
- **WHEN** 用户未聚焦某条消息
- **THEN** 该消息时间 MUST 以较淡的颜色显示
- **AND WHEN** 用户 hover 到该消息区域
- **THEN** 时间颜色 MUST 加深，但不得喧宾夺主覆盖正文阅读
