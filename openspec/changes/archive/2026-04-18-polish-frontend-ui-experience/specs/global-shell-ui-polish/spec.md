## ADDED Requirements

### Requirement: 全局黑白主题与中文界面
应用外壳 SHALL 统一采用黑白主题体系，并将首页、助手、设置及其相关全局可见界面文案统一为中文。允许在来源相关元素上使用轻量主题色点缀，但不得破坏整体黑白主基调。

#### Scenario: 切换浅色与深色主题
- **WHEN** 用户在应用中切换浅色或深色主题
- **THEN** 顶部导航、页面背景、按钮、设置面板和聊天容器 MUST 使用统一的黑白灰主题变量呈现

#### Scenario: 全局可见文案使用中文
- **WHEN** 用户浏览首页、助手、设置和常见空状态 / 错误提示
- **THEN** 系统 MUST 使用中文文案显示主要导航、操作名称和状态提示

### Requirement: 顶部导航统一 active 视觉语言
顶部导航中的首页、助手、设置入口 SHALL 使用同一套 active 视觉语言，并且设置按钮在任意 `/settings/*` 子路由下都必须被视为选中。

#### Scenario: 首页与助手选中态一致
- **WHEN** 用户位于首页或助手页面
- **THEN** 对应顶部导航项 MUST 使用与其它一级导航一致的 active 样式，例如下划线、强调色或等价选中标识

#### Scenario: 设置子路由保持选中
- **WHEN** 用户进入任意 `/settings/*` 子页面
- **THEN** 顶部“设置”入口 MUST 保持选中态，而不是仅在 `/settings` 根路径下高亮

### Requirement: 顶部控制按钮布局与样式统一
顶部“一键刷新”与主题切换按钮 SHALL 遵循统一的导航区布局规则，不得改变既有权限逻辑。

#### Scenario: 一键刷新位于首页和助手入口左侧
- **WHEN** 顶部导航渲染首页与助手入口
- **THEN** “一键刷新”按钮 MUST 放置在首页 / 助手入口的左侧，且保持现有登录与 level 权限判断不变

#### Scenario: 主题切换按钮为纯图标圆形按钮
- **WHEN** 顶部主题切换按钮显示
- **THEN** 该按钮 MUST 使用无文字、无边框的圆形图标样式，并保留可访问名称与悬浮说明
